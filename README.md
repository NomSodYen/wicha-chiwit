# วิชาชีวิต
เว็บแอปภาษาไทยสำหรับเรียนรู้ทักษะชีวิต ใช้งานบนมือถือและคอมพิวเตอร์

## ฟีเจอร์
- 47 บทใน 12 หมวด ครอบคลุมทุกหมวด รวมเหตุฉุกเฉิน การเงินการลงทุน และรายได้เสริม
- เส้นทางแนะนำ 5 เส้นทาง เช่น จบใหม่เริ่มงานแรก, เริ่มวางแผนการเงิน, มีงานประจำทำร้านเสริม
- สายด่วนที่ควรรู้ 16 เบอร์ แตะเพื่อโทรบนมือถือ
- หน้าแรกออกแบบตามแนวทาง [scroll-craft](https://github.com/nateherkai/scroll-craft) แบบ chaptered editorial: หน้าปกที่กระดาษซ้อนเป็นชั้น, บทที่ ๑ ที่ปากกาแดงขีดคำว่า "ไม่รู้" ตามการเลื่อน, ตัวอย่างหน้าบทเรียน, หมวดเลื่อนแนวนอน, ห้องสมุดบทเรียน และหน้าท้ายเล่มรวมสายด่วน (brief และผลตรวจอยู่ที่ `scrollcraft/builds/wicha-chiwit/BRIEF.md`)
- ค้นหาชื่อบท เนื้อหา และหมวด / กรองหมวด / ดูตามเส้นทาง
- บันทึกบทเรียน เช็กลิสต์ คำถามทบทวน สถานะเรียนจบ และปุ่มไปบทถัดไป
- เก็บข้อมูลด้วย localStorage ในเบราว์เซอร์ ไม่ส่งข้อมูลไปเซิร์ฟเวอร์ ไม่ซิงก์ข้ามอุปกรณ์
- ไม่มีบัญชีผู้ใช้ และไม่ขอข้อมูลบัตรประชาชน

## เปิดใช้งาน
ดาวน์โหลดไฟล์ทั้งหมดแล้วเปิด index.html ในเบราว์เซอร์ได้ หรือใช้ static web server:
```sh
python3 -m http.server 8000
```
จากนั้นเปิด http://localhost:8000
การเก็บข้อมูลเมื่อเปิดแบบ file:// ขึ้นกับเบราว์เซอร์ แนะนำใช้ผ่าน HTTP/HTTPS

## ไฟล์
- index.html: โครงหน้า
- style.css: รูปแบบ responsive
- data.js: หมวด บทเรียน คำถาม แหล่งข้อมูล เส้นทางแนะนำ (paths) และสายด่วน (hotlines)
- app.js: การค้นหา บันทึก เช็กลิสต์ ความคืบหน้า ปากกาแดง และ folio
- scrollcraft.js / scrollcraft.css: กลไกการเลื่อนจาก scroll-craft (MIT) ห้ามแก้ไฟล์นี้ ปรับดีไซน์ใน style.css
- icons.js: ไอคอนจาก Lucide (ISC)

## ขอบเขตเนื้อหา
บทเรียนเป็นแนวทางเบื้องต้นสำหรับประเทศไทย ไม่ใช่ระบบยื่นภาษี ตรวจสิทธิ หรือบริการราชการจริง
แหล่งทางการที่ค้นตรวจเมื่อ 4 พฤศจิกายน 2569 แนบในบทเรียนที่เกี่ยวข้อง
แต่ละบทมี: ทำไมต้องรู้ (ย่อหน้าอธิบาย), ขั้นตอนพร้อมคำอธิบาย, ตัวอย่างจริงพร้อมตัวเลข, ข้อผิดพลาดที่พบบ่อย, เช็กลิสต์, คำถามทบทวนพร้อมเฉลย และแหล่งอ้างอิงหลายแหล่ง
ตัวเลขที่ปรับตามกฎใหม่ (ตรวจ 5 พฤศจิกายน 2569): ฐานค่าจ้างประกันสังคม 17,500 บาท (สมทบสูงสุด 875 บาท) ตั้งแต่ 1 ม.ค. 2569, ผ่อนขั้นต่ำบัตรเครดิต 8% ถึงสิ้นปี 2569, ประกาศ สคบ. ธุรกิจให้เช่าที่อยู่อาศัย พ.ศ. 2568 (ผู้ให้เช่าตั้งแต่ 3 หน่วย)
รูปแบบข้อมูลบทเรียนใน data.js: why[], steps[{t, d}], example{title, body[]}, mistakes[{t, d}], explain, sources[{name, url}]
ประกาศเลือกตั้งที่แนบเป็นตัวอย่างเดิม ผู้ใช้ต้องตรวจประกาศสำหรับการเลือกตั้งครั้งที่จะไป
บทมารยาทไม่ตัดสินคุณค่าของคน บทเลือกตั้งไม่สนับสนุนพรรคหรือผู้สมัคร
